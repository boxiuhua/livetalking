## 常用命令

> 以下命令在 **PowerShell** 中运行。为简洁定义变量：`$py = "D:\miniconda3\envs\livetalking\python.exe"`

### 1. 启动服务（wav2lip + WebRTC）

```powershell
$py = "D:\miniconda3\envs\livetalking\python.exe"
cd D:\workspase\rust\LiveTalking
& $py app.py --transport webrtc --model wav2lip --avatar_id wav2lip256_avatar1
```

启动成功日志：`start http server; http://<serverip>:8010/index.html`

浏览器打开 **http://127.0.0.1:8010/index.html** → 点“开始连接” → 输入文字，数字人即说话（默认微软 EdgeTTS 中文语音）。

### 2. 查看服务是否在运行

```powershell
Get-NetTCPConnection -LocalPort 8010 -State Listen
```

有输出即在运行，`OwningProcess` 列是进程 PID。

### 3. 停止服务

```powershell
# 按端口找到并结束进程
$procId = (Get-NetTCPConnection -LocalPort 8010 -State Listen).OwningProcess | Select-Object -First 1
Stop-Process -Id $procId -Force
```

### 4. 重启服务

```powershell
# 先停
$procId = (Get-NetTCPConnection -LocalPort 8010 -State Listen -ErrorAction SilentlyContinue).OwningProcess | Select-Object -First 1
if ($procId) { Stop-Process -Id $procId -Force }
# 再启
$py = "D:\miniconda3\envs\livetalking\python.exe"
cd D:\workspase\rust\LiveTalking
& $py app.py --transport webrtc --model wav2lip --avatar_id wav2lip256_avatar1
```

### 5. 环境自检（确认 GPU 与依赖正常）

```powershell
$py = "D:\miniconda3\envs\livetalking\python.exe"
& $py -c "import torch; print('cuda', torch.cuda.is_available(), '|', torch.cuda.get_device_name(0))"
ffmpeg -version | Select-Object -First 1
```

## 其他启动方式

```powershell
# RTMP 推流（需填 --push_url）
& $py app.py --transport rtmp --model wav2lip --avatar_id wav2lip256_avatar1 --push_url rtmp://<地址>

# 虚拟摄像头输出（数字人作为系统摄像头设备）
& $py app.py --transport virtualcam --model wav2lip --avatar_id wav2lip256_avatar1

# 换端口（默认 8010）
& $py app.py --transport webrtc --model wav2lip --avatar_id wav2lip256_avatar1 --listenport 8020
```

> 也可以在 `config.yaml` 里改默认值（CLI 参数优先级高于 config.yaml）。

## 依赖 / 环境维护

```powershell
# 激活环境（交互式使用）
D:\miniconda3\Scripts\activate.bat livetalking

# 重新安装/补装依赖（缓存和临时目录都指向 D 盘，避开 C 盘和杀软干扰）
```

## 常见提示（正常现象）

- `funasr not installed → local ASR endpoint disabled`：本地语音识别是可选功能，**文字驱动不受影响**。需要语音输入再执行 `& $py -m pip install funasr modelscope`。
- 首次启动较慢：需加载 550 张图 + 模型上显存 + 预热，属正常。
- 后端日志 `inferfps`（GPU 推理帧率）与 `finalfps`（推流帧率）两者 ≥25 才算实时。

## 值守模式：无人时自动讲故事 / 唱歌（autohost.py）

让数字人在空闲时自动轮流讲故事、唱歌，循环不息。**纯外部脚本，不改引擎。**

```powershell
# 1. 先确保服务已启动，并在浏览器打开 index.html 点“开始连接”（建立会话）
# 2. 再运行值守脚本（自动发现会话）
$py = "D:\miniconda3\envs\livetalking\python.exe"
cd D:\workspase\rust\LiveTalking
& $py autohost.py
```

内容目录：
- `content\stories\*.txt` —— 故事文本（空行分段，逐段念）。已内置 3 篇温柔小故事，可自由增删。
- `content\songs\*.wav|mp3` —— 歌曲音频（放进去就会“唱”，口型自动对齐；为空则只讲故事）。

常用参数：

| 参数 | 默认 | 说明 |
|------|------|------|
| `--gap` | `4` | 静默多少秒后播下一条 |
| `--order` | `sequential` | `sequential` / `random` / `alternate`（故事歌曲交替） |
| `--loop` | `true` | 播完是否重头循环 |
| `--server` | `http://127.0.0.1:8010` | 服务地址 |
| `--sessionid` | 自动发现 | 指定会话 id（一般不用填） |

停止：在脚本窗口按 `Ctrl+C`。跑单元测试：`& $py tests\test_autohost.py`。

> 说明：脚本靠轮询 `/is_speaking` 判断空闲，有人打字触发对话时会自动让路（暂停内容），对话结束再恢复——为将来接入聊天预留。

## 注意事项

- **所有下载 / 安装都放 D 盘**（C 盘容量紧张）。装新包前先设置 `PIP_CACHE_DIR` 和 `TMP` 到 D 盘。
- `transformers` 当前为 5.13.0（仓库注释建议 4.46.2）；wav2lip 可用，若日后跑 musetalk/ultralight 的 whisper/hubert 报错，可降级：`& $py -m pip install "transformers==4.46.2"`。
- 换其他数字人模型（musetalk/ultralight）需另下对应模型与素材；musetalk 显存吃紧时用 `--batch_size 4`。
- `s3fd.pth` 仅在自制新形象（`genavatar.py`）时需要，wav2lip 日常推理用不到。
